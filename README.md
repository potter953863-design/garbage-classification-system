# 🗑️ 智能垃圾分类系统 (Smart Garbage Classification System)

一个基于深度学习（双模型融合）的智能垃圾分类系统，使用 PyTorch 和 Streamlit 构建。该系统旨在通过图像识别技术，帮助用户准确识别生活垃圾类别，并提供详细的回收建议和附近回收点导航。

> **当前版本特性**：采用 EfficientNetV2-S + EfficientNetV2-M 双模型融合架构，在清洗后的验证集上真实准确率达到 **91.01%**。

## ✨ 功能特性

### 🎯 核心识别
* **精准分类**：支持识别 44 种常见生活垃圾（如：易拉罐、快递纸袋、剩饭剩菜、废旧电池等）。
* **四大类别**：自动将识别结果映射为国标四大类（可回收物、有害垃圾、厨余垃圾、其他垃圾）。
* **多城市支持**：内置上海、北京、深圳、广州等城市的分类标准，可一键切换。

### 🛠️ 图像增强
* **一键优化**：自动检测低光照图片，提供“自动增强”选项（亮度调整、降噪、锐化），显著提升识别准确率。
* **对比预览**：提供增强前后的直观对比图。

### 📊 智能分析
* **双模型会诊**：采用 S版（灵巧型）和 M版（重型）双模型加权投票，极大降低误判率。
* **边界警告**：当模型对两个相似类别（如玻璃瓶 vs 塑料瓶）拿捏不准时，自动触发“临界警告”，并给出人工核查建议。
* **置信度展示**：不仅给出结果，还展示 Top 3 预测概率，让用户心中有数。

### 🏆 用户互动
* **成就系统**：记录用户的每一次环保行为，解锁“环保达人”、“分类大师”等 10+ 种成就徽章。
* **回收地图**：集成高德地图 API，一键查询附近的对应类别回收站（如：识别出电池，自动搜“有害垃圾回收点”）。

## 🔬 核心技术

本项目采用工业级计算机视觉方案，经过多轮迭代优化：

1.  **模型架构**：
    * **Backbone**: EfficientNetV2-S (320px) + EfficientNetV2-M (384px)
    * **Ensemble**: 采用加权平均融合策略 (0.4 * S + 0.6 * M)。
2.  **训练策略**：
    * **数据增强**: RandAugment + CutMix + Mixup
    * **优化器**: AdamW (初期) -> SGD (SWA 微调)
    * **损失函数**: Label Smoothing CrossEntropy
3.  **性能指标**：
    * **原始准确率**: 86.47% (含噪数据)
    * **清洗后准确率**: **91.01%** (真实能力)
